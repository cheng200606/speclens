## 2. Go/No-Go 判读（plan.md §2.4）

| 判据 | 实测 | 结论 |
|---|---|---|
| **Go（方法）**：M-lite 显著优于 B1（检出 +10pp 或误报 −20%，p<0.1） | 检出 +4.3pp（<10pp）；误报 +7.7pp（更差）；全部子集检验 p≥0.1 | ❌ **不成立** |
| **Go（规模/成本）**：B1 ≈ M-lite 但 B1 成本/上下文爆表 → RQ4 | 效果统计不可分（p=1.0）；B1 tokens = M-lite 的 **6.4×**（59.4K vs 9.3K tokens/case） | ✅ **成立（成本维度）** |
| **No-Go（方法）**：B1 全面占优且无成本劣势 | B1 检出更低、误报更低（均不显著），且有 6.4× 成本劣势 | ❌ 不触发 |

**判读：Go（RQ4 场景）。** 项目主线按 plan.md 预案调整为：

1. **RQ1/RQ3 measurement study 为主体**：规范知识对误报的压制效应（B0 0.539 → B1 0.077，
   p=0.031）是本 pilot 最干净的测量发现；错误分类学（哪些合规代码被 zero-shot 误报）价值直接。
2. **RQ4 成本–效果为方法侧卖点**：B1 成本随（规范数 × 规范长度 × 仓库规模）线性放大，
   规则路由有界——需在 1k/10k/50k 行仓库梯度下量化（本 pilot 单规范未触发上下文失效，
   deepseek-flash 1M 窗口容纳 59K tokens 绰绰有余）。
3. **RQ2（规则验证管线的增益）未获支持，不升级为全量实验**，待 M-verified 退化修复后重议（§3）。

## 3. 执行中发现的问题（归入 I3）

1. **M-verified 相对 M-lite 退化**：检出 −13.0pp（4 个预测翻转：漏掉 TS-029/TS-031/TS-040
   三个 R-011 族违规 + 新增 TS-011 一个误报），规则命中率 0.714 → 0.444。原始输出显示
   TS-031 在 M-verified 下返回空 findings——疑似 R-011 匹配规则被验证关过滤或验证后
   prompt 改变判定，**无法归因：验证关逐规则结果未随 run 归档（可诊断性缺口）**。
   I3 动作：`verify_rules` 产出（每条规则的 gate1/2/3 结论与理由）落盘到 run 目录；再重跑对照。
2. **对齐覆盖率仍为 7/12**（rules_diagnostic.json）：描述性句（R-001/R-002/R-005）确定性
   提取器不召回——I1 D2 结论不变，LLM 规则合成仍是必要投资，但优先级让位于 RQ4 主线。
3. **报告口径**：`make_report` 的 rule_match 对基线显示 0.0，易误读为缺陷；应在报告中
   注明该指标只对 M 路径可解释（本次已在 §1.3 加注，报告模板待改）。

## 4. 本轮结果的局限（写入论文前必须补齐）

1. **单模型 / 单运行 / 单规范**：plan §2.4 设计为 2 模型 × 2 runs × 40 cases；
   本 pilot 为 1 模型 × 1 run（temperature 0）× 40 cases。第二模型需用户提供第二个 API key。
2. **规范熟悉度**：probe 0.9–1.0，unseen 前提不成立（§1.2）。
3. **23/40 案例为 AI 起草（origin=synthetic）**：按标注指南 §5「不进核心判断集」——
   本 pilot 刻意纳入并披露；**用户人工复核（逐条确认/修正/否决）是把结果升级为论文素材的前提**。
4. **子集检验功效低**：n=23/13 上 +10pp/−20% 判据几乎不可能显著；否定性结果 ≠ 最终否定，
   扩样（240 条）与多运行后方有足够功效。
5. **成本口径**：`estimated_cost_usd=null`（未配价格表）；tokens 为唯一硬成本数据，
   论文需按 `usage.json` 自行换算。

## 5. I3 建议（按优先级）

1. **验证关可诊断性 + M-verified 修复**（对应 §3-1）：gate 结果归档 → 重跑 M-verified → 归因。
2. **用户复核 23 条 synthetic 案例**（解锁论文级基准；同时启动自我盲标/第二标注人 κ 预案）。
3. **RQ4 成本–规模实验**：仓库规模梯度 + 多规范并发场景设计（新增 config 轴），B1 vs M 的
   成本–效果曲线；补 B2 (RAG) / B3 (静态检查) 基线。
4. **错误分类学预研**：把 B0 的 7 个误报 case 与 B1/M 的漏检 case 逐条归类（RQ3 骨架）。
5. 第二模型接入（双供应商对照）；LLM 规则合成（提高对齐覆盖 7/12 → 目标 ≥10/12）。
